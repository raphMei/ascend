À essayer

  • Toucher la case ronde : la couleur envahit la carte, étincelles, anneau du jour qui monte, vibration.
  • Balayer une carte vers la droite = fait, vers la gauche = passer (avec Annuler).
  • Appui long (une demi-seconde) sur une carte : menu de verre.
  • Toucher une carte : elle s'agrandit en page de détail (zoom iOS).
  • Démarrer sur la carte « maintenant » : mini-lecteur en bas, qui s'agrandit en plein écran (temps accéléré ×30 pour la démo).
  • Défiler : le titre se réduit en barre de verre.
  • Matin / Après-midi / Soir (en haut) : halos de couleur et tâche « maintenant » changent ; le soir, l'interface se calme.
  • Tout cocher : célébration, palier de série à 7 jours.

Le fond, le verre et les couleurs diffèrent selon A, B et C. Les icônes et textes sont ceux d'Ascend.
